# Веб-программирование · Урок 1. Как работает веб и какие нужны инструменты

## Цели урока
- Понять, как браузер получает страницу с сервера
- Узнать роли HTML, CSS и JavaScript
- Подготовить рабочее место и создать первую страницу

## Теория
Когда вы вводите адрес сайта, происходит цепочка:
1. **Браузер (клиент)** ищет IP-адрес по домену через DNS
2. Отправляет **HTTP-запрос** на сервер
3. **Сервер** возвращает ответ: HTML, CSS, JS, изображения
4. Браузер собирает всё и рисует страницу

**Три кита фронтенда**
| Технология | Отвечает за | Пример |
|---|---|---|
| HTML | структуру и содержимое | заголовки, абзацы, ссылки |
| CSS | внешний вид | цвета, шрифты, расположение |
| JavaScript | поведение | клики, анимации, запросы |

**Фронтенд** — то, что видит пользователь. **Бэкенд** — серверная часть (PHP, Python, C# и др.).

## Инструменты
- Редактор: **VS Code** (расширение Live Server)
- Браузер: Chrome или Firefox
- DevTools: клавиша `F12` — инспектор элементов, консоль, сеть
- Git и аккаунт GitHub (понадобятся позже)

## Первая страница
Создайте папку `my-site` и файл `index.html`:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Моя первая страница</title>
</head>
<body>
  <h1>Привет, веб!</h1>
  <p>Это моя первая страница.</p>
</body>
</html>
```
Откройте файл в браузере или запустите **Live Server** (правая кнопка → *Open with Live Server*).

## Изучаем чужие сайты
Откройте любой сайт → `F12` → вкладка **Elements**. Наведите на элемент, измените текст — страница изменится (только у вас на экране, сайт остаётся прежним).

## Практика
1. Создайте страницу с заголовком с вашим именем и абзацем о ваших увлечениях.
2. Откройте DevTools на любом сайте и измените текст заголовка.
3. На вкладке **Network** найдите, какие файлы загрузила страница.
