# C++ · Урок 12. Ссылки и передача параметров

## Цели урока
- Использовать ссылки
- Выбирать способ передачи параметров

## Ссылка
Ссылка — другое имя для той же переменной:
```cpp
int x = 5;
int& r = x;      // r — псевдоним x
r = 10;          // x стало 10
```
Ссылку нужно инициализировать сразу, а после создания она не может «переехать» на другую переменную.

## Способы передачи параметров
```cpp
void byValue(int a)        { a = 100; }        // копия: оригинал не меняется
void byRef(int& a)         { a = 100; }        // ссылка: оригинал меняется
void byConstRef(const std::string& s) { /* только чтение, без копирования */ }
void byPtr(int* a)         { if (a) *a = 100; }// указатель
```

## Обмен через ссылки
```cpp
void swapValues(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}
int x = 1, y = 2;
swapValues(x, y);       // x == 2, y == 1
```

## Возврат нескольких значений
```cpp
void minMax(const std::vector<int>& v, int& mn, int& mx) {
    mn = mx = v[0];
    for (int x : v) {
        if (x < mn) mn = x;
        if (x > mx) mx = x;
    }
}
```
Или через `std::pair` / структуру:
```cpp
std::pair<int, int> minMax2(const std::vector<int>& v);
auto [mn, mx] = minMax2(v);      // структурированные привязки C++17
```

## Правило выбора
- Небольшие типы (`int`, `double`, `char`) → по значению
- Большие объекты (`string`, `vector`), которые только читаем → `const T&`
- Нужно изменить оригинал → `T&`
- Параметр может отсутствовать → указатель

## Типичные ошибки
- Возврат ссылки на локальную переменную
- Передача временного значения в неконстантную ссылку
- Изменение объекта через `&`, когда хотели работать с копией

## Практика
1. Функция `increment(int& x)`.
2. Функция, разделяющая число на целую и дробную часть через ссылки.
3. Функция `print(const vector<int>&)` без копирования.
