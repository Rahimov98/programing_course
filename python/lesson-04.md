# Python · Урок 4. Операторы

## Цели урока
- Пользоваться арифметическими, сравнения и логическими операторами
- Знать приоритет операций

## Арифметические
```python
7 + 2    # 9
7 - 2    # 5
7 * 2    # 14
7 / 2    # 3.5  (всегда float)
7 // 2   # 3    (целочисленное деление)
7 % 2    # 1    (остаток)
7 ** 2   # 49   (степень)
```

**Составное присваивание:** `x += 1`, `x -= 2`, `x *= 3`, `x //= 2`.

## Сравнения (результат — `bool`)
`==`, `!=`, `<`, `>`, `<=`, `>=`
```python
5 == 5.0        # True
"a" < "b"       # True
1 < x < 10      # цепочка сравнений
```

## Логические
```python
True and False   # False
True or False    # True
not True         # False
age = 20
print(age >= 18 and age < 65)
```

## Оператор принадлежности и тождества
```python
"a" in "cat"          # True
3 not in [1, 2, 3]    # False
x is None             # проверка на None
```

## Приоритет
`**` → унарные `-x` → `* / // %` → `+ -` → сравнения → `not` → `and` → `or`. Сомневаетесь — ставьте скобки.

## Типичные ошибки
- `=` (присваивание) вместо `==` (сравнение)
- Ожидали целое от `/`, а получили `float` — используйте `//`
- Сравнение чисел с плавающей точкой: `0.1 + 0.2 == 0.3` → `False`

## Практика
1. Найдите последнюю цифру числа `1987` и число без последней цифры (`%`, `//`).
2. Проверьте, что число `n` чётное и больше 10.
3. Вычислите `2 ** 3 ** 2` и объясните результат.
