# Веб · Урок 6. Семантическая вёрстка

## Цели урока
- Использовать семантические теги HTML5
- Понять пользу для SEO и доступности
- Структурировать страницу правильно

## Теория

**Семантические теги**
```html
<header>…</header>   <!-- шапка сайта или секции -->
<nav>…</nav>         <!-- навигация -->
<main>…</main>       <!-- основное содержимое (один на страницу) -->
<article>…</article> <!-- самостоятельный фрагмент (пост, новость) -->
<section>…</section> <!-- тематический раздел -->
<aside>…</aside>     <!-- боковая панель, доп. информация -->
<footer>…</footer>   <!-- подвал -->
```

**Пример структуры**
```html
<body>
  <header>
    <nav>
      <a href="/">Главная</a>
      <a href="/about">О нас</a>
    </nav>
  </header>

  <main>
    <article>
      <h1>Заголовок статьи</h1>
      <p>Текст…</p>
    </article>
    <aside>
      <h2>Похожие материалы</h2>
    </aside>
  </main>

  <footer>
    <p>© 2026</p>
  </footer>
</body>
```

**Другие полезные теги**
- `<figure>` + `<figcaption>` — изображение с подписью
- `<time datetime="2026-01-15">15 января</time>`
- `<address>` — контактная информация
- `<mark>` — выделенный фрагмент

**Зачем семантика**
- Поисковики лучше понимают структуру
- Скринридеры озвучивают роли элементов
- Код читаемее для людей

**div и span** — когда нет подходящего семантического тега:
- `div` — блочный контейнер
- `span` — строчный контейнер

## Типичные ошибки
- Всё подряд в `div`
- Несколько `<main>`
- `<section>` без заголовка

## Практика
1. Переделайте «визитку» на семантические теги.
2. Сделайте макет: header + nav, main с article, footer.
3. Добавьте figure с изображением и подписью.

## Проверь себя
1. Чем `<article>` отличается от `<section>`?
2. Сколько раз можно использовать `<main>`?
3. Зачем семантика, если визуально можно обойтись div?
