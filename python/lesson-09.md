# Python · Урок 9. Словари и множества

## Цели урока
- Хранить данные в парах «ключ — значение»
- Использовать множества для уникальных элементов

## Словари
```python
student = {"name": "Алишер", "age": 21, "city": "Душанбе"}
student["name"]              # 'Алишер'
student["group"] = "A-101"   # добавить
student["age"] = 22          # изменить
del student["city"]          # удалить
student.get("phone", "нет")  # безопасное чтение
"age" in student             # проверка ключа
```

**Перебор**
```python
for key in student:
    print(key, student[key])
for key, value in student.items():
    print(f"{key}: {value}")
student.keys(), student.values()
```

**Пример: подсчёт слов**
```python
text = "да нет да да нет"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1
print(counts)   # {'да': 3, 'нет': 2}
```

## Множества
```python
a = {1, 2, 3, 3}          # {1, 2, 3}
b = {3, 4, 5}
a | b     # объединение
a & b     # пересечение {3}
a - b     # разность {1, 2}
a.add(10)
set([1, 1, 2])   # удаление дублей из списка
```
Пустое множество: `set()` (а `{}` — пустой словарь).

## Типичные ошибки
- `KeyError` при чтении отсутствующего ключа — используйте `.get()`
- Ключом словаря могут быть только неизменяемые объекты (не список)
- Порядок элементов множества не гарантирован
