# C++ · Урок 16. Конструкторы и деструкторы

## Цели урока
- Создавать и уничтожать объекты правильно
- Понимать копирование и правило трёх/пяти

## Конструкторы
```cpp
class Person {
    std::string name;
    int age;
public:
    Person() : name("Без имени"), age(0) {}                      // по умолчанию
    Person(const std::string& n, int a) : name(n), age(a) {}      // с параметрами
    Person(const std::string& n) : Person(n, 18) {}               // делегирование
};

Person a;
Person b("Али", 21);
Person c = Person("Мадина");
```

## Деструктор
Вызывается автоматически при уничтожении объекта:
```cpp
class Logger {
public:
    Logger()  { std::cout << "Открыт лог\n"; }
    ~Logger() { std::cout << "Закрыт лог\n"; }
};

int main() {
    Logger log;          // при выходе из main вызовется деструктор
}
```
Деструктор нужен, чтобы освободить ресурсы (память, файлы, соединения).

## Копирование
Компилятор создаёт копирующий конструктор, который копирует поля. Для указателей это опасно (обе копии указывают на одну память):
```cpp
class Buffer {
    int* data;
    size_t size;
public:
    Buffer(size_t n) : data(new int[n]{}), size(n) {}
    Buffer(const Buffer& other) : data(new int[other.size]), size(other.size) {
        std::copy(other.data, other.data + size, data);       // глубокое копирование
    }
    Buffer& operator=(const Buffer& other) {
        if (this != &other) {
            delete[] data;
            size = other.size;
            data = new int[size];
            std::copy(other.data, other.data + size, data);
        }
        return *this;
    }
    ~Buffer() { delete[] data; }
};
```
**Правило трёх:** если нужен свой деструктор, обычно нужны и копирующий конструктор, и оператор присваивания (в C++11 — ещё и перемещающие: правило пяти).

## default и delete
```cpp
Person() = default;
Person(const Person&) = delete;     // запретить копирование
```

## Порядок вызова
Конструкторы: сначала базовый класс, потом поля, потом тело. Деструкторы — в обратном порядке.

## Типичные ошибки
- Не освободили ресурсы в деструкторе
- Поверхностное копирование указателей → двойной `delete`
- Использование `explicit` не помечено для конструкторов с одним параметром
