# Веб · Урок 3. Текст, ссылки, изображения

## Цели урока
- Размечать текст: заголовки, абзацы, выделения
- Создавать ссылки
- Вставлять изображения

## Теория

**Заголовки и текст**
```html
<h1>Главный заголовок</h1>   <!-- один на страницу -->
<h2>Подзаголовок</h2>
<h3>…</h3>
<p>Обычный абзац текста.</p>
<strong>Важный текст</strong>   <!-- жирный, смысловой -->
<em>Акцент</em>                 <!-- курсив, смысловой -->
<br>                            <!-- перенос строки (редко) -->
<hr>                            <!-- горизонтальная линия -->
```

**Ссылки**
```html
<a href="https://example.com">Внешняя ссылка</a>
<a href="about.html">Внутренняя страница</a>
<a href="#contacts">Якорь на этой странице</a>
<a href="mailto:me@example.com">Написать письмо</a>
<a href="https://example.com" target="_blank" rel="noopener">В новой вкладке</a>
```

**Изображения**
```html
<img src="photo.jpg" alt="Описание фото" width="400">
<img src="https://via.placeholder.com/300" alt="Заглушка">
```
- `src` — путь к файлу или URL
- `alt` — описание (обязательно для доступности и SEO)
- Желательно указывать `width`/`height` или через CSS

**Специальные символы**
```html
&lt; &gt; &amp; &quot; &nbsp;  <!-- < > & " неразрывный пробел -->
```

## Типичные ошибки
- Несколько `<h1>` без нужды
- Ссылка без `href`
- Картинка без `alt`
- Путь к файлу с ошибкой (регистр, слэши)

## Практика
1. Страница «О себе»: заголовок, 2–3 абзаца, выделения.
2. Добавьте ссылку на любимый сайт и mailto.
3. Вставьте изображение (своё или placeholder) с осмысленным alt.

## Проверь себя
1. Чем `<strong>` отличается от `<b>`?
2. Зачем `alt` у картинки?
3. Что делает `target="_blank"`?
