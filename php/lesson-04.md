# PHP · Урок 4. Условия

## Цели урока
- Писать `if / elseif / else`
- Использовать `switch` и тернарный оператор
- Понимать truthy/falsy значения

## Теория

**if / else**
```php
$age = 18;

if ($age >= 18) {
    echo "Совершеннолетний";
} elseif ($age >= 14) {
    echo "Подросток";
} else {
    echo "Ребёнок";
}
```

**Тернарный оператор**
```php
$status = ($age >= 18) ? "взрослый" : "несовершеннолетний";
$city = $city ?? "Неизвестно";   // null coalescing (PHP 7+)
$name = $name ?: "Гость";        // если falsy — "Гость"
```

**switch**
```php
$day = 3;
switch ($day) {
    case 1:
        echo "Понедельник";
        break;
    case 2:
        echo "Вторник";
        break;
    case 3:
        echo "Среда";
        break;
    default:
        echo "Другой день";
}
```

Без `break` выполняется «провал» (fall-through).

**Match (PHP 8+)**
```php
$result = match($day) {
    1, 2, 3, 4, 5 => "Будни",
    6, 7 => "Выходные",
    default => "Неизвестно",
};
```

## Типичные ошибки
- Забыли фигурные скобки при нескольких операторах
- `if ($x = 5)` — присваивание вместо сравнения
- Сравнение с `null` через `==` вместо `===` или `is_null()`

## Практика
1. По оценке (0–100) выведите «отлично / хорошо / удовлетворительно / неуд».
2. Определите время суток по часу (утро / день / вечер / ночь).
3. С помощью `match` или `switch` выведите название месяца по номеру.

1. Чем `??` отличается от `?:`?
2. Зачем нужен `break` в `switch`?
3. Какие значения считаются falsy в PHP?
