# JavaScript · Урок 3. Операторы и приведение типов

## Цели урока
- Использовать арифметические, сравнения и логические операторы
- Понимать разницу между `==` и `===`

## Арифметика
```js
7 + 2; 7 - 2; 7 * 2;
7 / 2;    // 3.5
7 % 2;    // 1
2 ** 10;  // 1024
let x = 5;
x++; x--; x += 3; x *= 2;
```

## Сравнение
```js
5 == "5";    // true  (нестрогое, с приведением типа)
5 === "5";   // false (строгое, без приведения)
5 !== "5";   // true
3 > 2; 3 >= 3; 2 < 1;
```
**Всегда используйте `===` и `!==`.**

## Логические операторы
```js
true && false;   // false
true || false;   // true
!true;           // false
```
Они возвращают одно из значений операндов:
```js
const name = userName || "Гость";       // значение по умолчанию
const city = user && user.city;          // защита от null
const port = config.port ?? 3000;        // ?? — только для null/undefined
const zip = user?.address?.zip;          // необязательная цепочка
```

## Приведение типов
```js
"5" + 3;        // "53" (строка)
"5" - 3;        // 2    (число)
Number("42");   // 42
Number("abc");  // NaN
parseInt("15px");   // 15
parseFloat("3.14"); // 3.14
String(123); Boolean("text");
```

## Ложные значения
`false`, `0`, `""`, `null`, `undefined`, `NaN` — всё остальное «истинно».

## Типичные ошибки
- `"5" + 3` даёт `"53"`
- `NaN === NaN` → `false`; проверяйте `Number.isNaN(x)`
- Используют `||` там, где нужно `??` (число `0` тоже «ложное»)

## Практика
1. Предскажите результат: `"10" / 2`, `"a" * 2`, `true + 1`, `[] + []`.
2. Напишите выражение, дающее значение по умолчанию для пустой строки.
3. Приведите введённое пользователем значение к числу и проверьте на `NaN`.

## Проверь себя
1. Чем `==` отличается от `===`?
2. Что делает оператор `??`?
3. Что даст `Number("")`?
