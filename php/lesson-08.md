# PHP · Урок 8. Строки

## Цели урока
- Работать со строками: длина, поиск, замена, разбиение
- Понимать разницу между одинарными и двойными кавычками
- Использовать основные строковые функции

## Теория

**Кавычки и интерполяция**
```php
$name = "Алишер";
echo "Привет, $name!";     // Привет, Алишер!
echo 'Привет, $name!';     // Привет, $name!
echo "Длина: " . strlen($name);
```

**Основные функции**
```php
$s = "  Hello, PHP!  ";

strlen($s);                 // длина в байтах
mb_strlen($s, "UTF-8");     // длина в символах (для кириллицы)
trim($s);                   // убрать пробелы по краям
strtolower("PHP");          // "php"
strtoupper("php");          // "PHP"
str_replace("PHP", "World", $s);
substr($s, 0, 5);           // "  Hel"
strpos($s, "PHP");          // позиция или false
explode(",", "a,b,c");      // ["a", "b", "c"]
implode("-", ["a", "b"]);   // "a-b"
sprintf("Мне %d лет", 21);  // "Мне 21 лет"
```

**Для кириллицы** используйте функции с префиксом `mb_` (нужно расширение mbstring):
```php
mb_strtolower("ПРИВЕТ", "UTF-8");
mb_substr("Привет", 0, 3, "UTF-8");  // "При"
```

**Heredoc / Nowdoc**
```php
$text = <<<EOT
Многострочный
текст с $name
EOT;
```

## Типичные ошибки
- `strlen("привет")` даёт 12 (байты UTF-8), а не 6
- `strpos` возвращает `0` при совпадении в начале — проверяйте `=== false`
- Конкатенация через `+` вместо `.`

## Практика
1. Посчитайте количество символов в строке с кириллицей.
2. Замените все пробелы на подчёркивания.
3. Разбейте строку `"яблоко,банан,вишня"` в массив и выведите каждый элемент с новой строки.

## Проверь себя
1. Чем одинарные кавычки отличаются от двойных?
2. Зачем `mb_strlen` вместо `strlen`?
3. Как безопасно проверить, что подстрока не найдена?
