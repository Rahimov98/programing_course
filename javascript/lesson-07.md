# JavaScript · Урок 7. Стрелочные функции и область видимости

## Цели урока
- Писать стрелочные функции
- Понимать блочную и функциональную область видимости и замыкания

## Стрелочные функции
```js
const add = (a, b) => a + b;
const square = x => x * x;
const hello = () => console.log("Привет");
const full = (a, b) => {
  const sum = a + b;
  return sum * 2;
};
```
Для короткого выражения `return` и `{}` не нужны. Стрелочные функции идеально подходят как аргументы:
```js
[1, 2, 3].map(x => x * 2);   // [2, 4, 6]
setTimeout(() => console.log("Прошла секунда"), 1000);
```

## Область видимости
```js
const g = "глобальная";
function test() {
  const local = "локальная";
  if (true) {
    let block = "блочная";
  }
  // console.log(block);  // ReferenceError
}
```
`let` и `const` видны только внутри своего блока `{ }`. Внутренняя функция видит переменные внешней.

## Замыкания
Функция «помнит» переменные из места, где была создана:
```js
function counter() {
  let count = 0;
  return () => ++count;
}
const next = counter();
next();  // 1
next();  // 2
```
Так делают приватные данные и фабрики функций.

## this в стрелочных функциях
У стрелочной функции нет собственного `this` — она берёт его из окружения. Поэтому как метод объекта её использовать не стоит.

## Типичные ошибки
- Объект в стрелочной функции без скобок: `() => { a: 1 }` — нужно `() => ({ a: 1 })`
- Использование `var` и путаница с областью видимости
- Стрелочная функция как метод, использующий `this`
