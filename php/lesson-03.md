# PHP · Урок 3. Операторы

## Цели урока
- Использовать арифметические, сравнения, логические и строковые операторы
- Понять приоритет и инкремент/декремент

## Теория

**Арифметические**
```php
$a = 10; $b = 3;
echo $a + $b;   // 13
echo $a - $b;   // 7
echo $a * $b;   // 30
echo $a / $b;   // 3.333...
echo $a % $b;   // 1 (остаток)
echo $a ** $b;  // 1000 (степень)
```

**Присваивание с операцией**
```php
$x = 5;
$x += 3;   // 8
$x *= 2;   // 16
$x .= "!"; // "16!" (конкатенация)
```

**Инкремент / декремент**
```php
$n = 5;
echo $n++;  // 5, потом $n = 6
echo ++$n;  // 7
```

**Сравнение**
```php
5 == "5";    // true  (нестрогое)
5 === "5";   // false (строгое: тип + значение)
5 != 3;      // true
5 !== "5";   // true
5 > 3;       // true
5 <=> 3;     // 1 (spaceship: -1, 0, 1)
```

**Логические**
```php
true && false;  // false (и)
true || false;  // true  (или)
!true;          // false (не)
```

**Строки**
```php
$a = "Hello";
$b = "World";
echo $a . " " . $b;   // Hello World
echo "Привет, $name!"; // интерполяция в двойных кавычках
echo 'Привет, $name!'; // литерально
```

## Типичные ошибки
- `=` вместо `==` в условии
- Деление на ноль → `INF` или Warning
- Конкатенация через `+` вместо `.`

## Практика
1. Посчитайте площадь круга (радиус 5, π ≈ 3.14159).
2. Проверьте, чётное ли число 17 (`%`).
3. Сложите строки «PHP» и «8» через `.` и через `+`, сравните результат.

2. Что делает оператор `.=`?
3. Какой результат у `true && 0`?
