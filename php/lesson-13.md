# PHP · Урок 13. Сессии

## Цели урока
- Запускать и использовать сессии
- Хранить данные пользователя между запросами
- Уничтожать сессию (выход)

## Теория

Сессия — способ сохранить данные на сервере и связать их с браузером через cookie `PHPSESSID`.

**Старт**
```php
<?php
session_start();  // обязательно до любого вывода

$_SESSION["user"] = "Алишер";
$_SESSION["cart"] = ["товар1", "товар2"];
```

**Чтение**
```php
session_start();
echo $_SESSION["user"] ?? "Гость";
```

**Удаление данных**
```php
unset($_SESSION["cart"]);           // один ключ
$_SESSION = [];                     // все данные
session_destroy();                  // уничтожить сессию
// после destroy cookie ещё жива — лучше также:
setcookie(session_name(), "", time() - 3600, "/");
```

**Проверка входа**
```php
session_start();
if (empty($_SESSION["user_id"])) {
    header("Location: login.php");
    exit;
}
```

**Регенерация ID (защита от fixation)**
```php
session_regenerate_id(true);
```

## Типичные ошибки
- `session_start()` после вывода HTML → «headers already sent»
- Забыли `exit` после `header("Location: ...")`
- Хранение паролей в сессии (никогда!)

## Практика
1. Страница `login.php`: форма логина, при «успехе» пишите имя в `$_SESSION` и редирект.
2. Страница `profile.php`: покажите имя из сессии или редирект на логин.
3. Страница `logout.php`: уничтожьте сессию и верните на главную.

## Проверь себя
1. Где физически хранятся данные сессии?
2. Зачем `session_regenerate_id`?
3. Что будет, если вызвать `session_start()` дважды?
