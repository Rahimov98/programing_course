# SQL · Урок 1. Введение в базы данных

## Цели урока
- Понять, что такое база данных, таблица, строка и столбец
- Установить инструмент для практики
- Выполнить первый запрос

## Теория
**База данных (БД)** — организованное хранилище данных. В реляционной БД данные лежат в **таблицах**: столбцы задают поля (имя, возраст), строки — записи. **SQL** (Structured Query Language) — язык, на котором мы создаём таблицы, добавляем, ищем и изменяем данные.

Популярные СУБД: SQLite, MySQL, PostgreSQL, SQL Server. Основы SQL одинаковы во всех.

| id | name   | city     | age |
|----|--------|----------|-----|
| 1  | Алишер | Душанбе  | 21  |
| 2  | Мадина | Худжанд  | 19  |

## Установка для практики
Самый простой вариант — **SQLite**:
- Онлайн: [sqliteonline.com](https://sqliteonline.com/) — ничего ставить не нужно
- Локально: **DB Browser for SQLite** или команда `sqlite3` в терминале

## Первые запросы
```sql
-- создаём таблицу
CREATE TABLE students (
    id   INTEGER PRIMARY KEY,
    name TEXT,
    city TEXT,
    age  INTEGER
);

-- добавляем данные
INSERT INTO students (name, city, age) VALUES ('Алишер', 'Душанбе', 21);
INSERT INTO students (name, city, age) VALUES ('Мадина', 'Худжанд', 19);

-- читаем данные
SELECT * FROM students;
```

**Разбор**
- `CREATE TABLE` — создаёт таблицу
- `INSERT INTO ... VALUES` — добавляет строку
- `SELECT * FROM ...` — выбирает все столбцы (`*`) из таблицы
- `--` — комментарий
- Ключевые слова принято писать заглавными; в конце запроса ставится `;`

## Типичные ошибки
- Забыли кавычки у текста: `'Алишер'`
- Опечатка в имени таблицы или столбца
- Запятая после последнего столбца в `CREATE TABLE`

## Практика
1. Создайте таблицу `books` со столбцами `id`, `title`, `author`, `year`.
2. Добавьте 3 книги.
3. Выведите все записи командой `SELECT * FROM books;`.
