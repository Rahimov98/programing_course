# PHP · Урок 7. Массивы

## Цели урока
- Создавать индексированные и ассоциативные массивы
- Обходить, добавлять, удалять элементы
- Использовать основные функции работы с массивами

## Теория

**Индексированный массив**
```php
$fruits = ["яблоко", "банан", "вишня"];
// или
$fruits = array("яблоко", "банан", "вишня");

echo $fruits[0];     // яблоко
$fruits[] = "груша"; // добавить в конец
```

**Ассоциативный массив**
```php
$user = [
    "name" => "Мадина",
    "age"  => 21,
    "city" => "Душанбе"
];

echo $user["name"];  // Мадина
```

**Многомерный**
```php
$matrix = [
    [1, 2, 3],
    [4, 5, 6]
];
echo $matrix[1][2];  // 6
```

**Полезные функции**
```php
count($fruits);              // количество
in_array("банан", $fruits);  // true
array_key_exists("age", $user); // true
array_push($fruits, "киви"); // добавить
array_pop($fruits);          // удалить последний
unset($user["city"]);        // удалить элемент
sort($fruits);               // сортировка по значениям
ksort($user);                // сортировка по ключам
array_keys($user);           // ["name", "age"]
array_values($user);         // ["Мадина", 21]
array_merge($a, $b);         // объединение
```

**foreach**
```php
foreach ($user as $key => $value) {
    echo "$key: $value\n";
}
```

## Типичные ошибки
- Обращение к несуществующему ключу → Warning (в PHP 8+ может быть Error)
- `count(null)` → Warning
- Путаница между `[]` и `array()`

## Практика
1. Создайте массив из 5 городов и выведите его через `foreach`.
2. Создайте ассоциативный массив «товар → цена» и найдите сумму.
3. Удалите один элемент и добавьте новый.
