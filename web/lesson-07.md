# Веб · Урок 7. CSS: подключение и селекторы

## Цели урока
- Подключать CSS тремя способами
- Использовать селекторы: тег, класс, id, комбинаторы
- Понимать специфичность

## Теория

**Способы подключения**
```html
<!-- 1. Внешний файл (предпочтительно) -->
<link rel="stylesheet" href="styles.css">

<!-- 2. Внутри страницы -->
<style>
  h1 { color: blue; }
</style>

<!-- 3. Инлайн (избегать) -->
<p style="color: red;">Текст</p>
```

**Основные селекторы**
```css
h1 { }                    /* тег */
.intro { }                /* класс */
#header { }               /* id (один на страницу) */
* { }                     /* все элементы */

p.note { }                /* тег + класс */
div p { }                 /* потомки */
div > p { }               /* прямые дети */
h1 + p { }                /* соседний следующий */
h1 ~ p { }                /* все следующие соседи */
```

**Классы и id в HTML**
```html
<p class="intro highlight">Текст</p>
<div id="main-content">…</div>
```

**Специфичность (кто победит)**
1. Инлайн-стиль
2. id
3. класс / атрибут / псевдокласс
4. тег / псевдоэлемент

При равенстве — тот, что ниже в коде.

**Каскад и наследование**
Стили «стекаются». Многие свойства (цвет, шрифт) наследуются детьми.

## Типичные ошибки
- Класс с точкой в HTML: `class=".intro"` — неверно
- id для стилизации «всего подряд» (лучше классы)
- Слишком высокая специфичность → сложно переопределять

## Практика
1. Подключите внешний `styles.css`.
2. Стилизуйте h1 по тегу, абзац по классу, шапку по id.
3. Сделайте так, чтобы ссылки внутри nav отличались от обычных.

## Проверь себя
1. Какой способ подключения CSS лучше и почему?
2. Чем класс отличается от id?
3. Что такое специфичность?
