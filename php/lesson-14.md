# PHP · Урок 14. Cookies

## Цели урока
- Устанавливать, читать и удалять cookies
- Понимать параметры cookie (срок, путь, безопасность)
- Отличать cookies от сессий

## Теория

Cookie — небольшие данные, которые браузер хранит и отправляет с каждым запросом.

**Установка**
```php
<?php
setcookie("theme", "dark", time() + 86400 * 30, "/");  // 30 дней
setcookie("lang", "ru", [
    "expires"  => time() + 86400 * 365,
    "path"     => "/",
    "secure"   => true,      // только HTTPS
    "httponly" => true,      // недоступна из JS
    "samesite" => "Lax"
]);
```

**Чтение**
```php
$theme = $_COOKIE["theme"] ?? "light";
```

**Удаление**
```php
setcookie("theme", "", time() - 3600, "/");
```

**Сессия vs Cookie**

| | Сессия | Cookie |
|---|---|---|
| Хранение | На сервере | В браузере |
| Размер | Больше | ~4 КБ |
| Безопасность | Выше (данные не у клиента) | Ниже |
| Срок | До закрытия браузера (обычно) | Можно задать |

**Практика: «Запомнить меня»**
```php
// при логине
if (!empty($_POST["remember"])) {
    $token = bin2hex(random_bytes(32));
    setcookie("remember", $token, time() + 86400 * 30, "/", "", false, true);
    // сохранить $token в БД рядом с user_id
}
```

## Типичные ошибки
- `setcookie` после вывода → headers already sent
- Забыли `path=/` — cookie видна только в текущей папке
- Хранение пароля или чувствительных данных в cookie

## Практика
1. Установите cookie с выбранной темой (light/dark) на 7 дней.
2. На другой странице прочитайте cookie и примените стиль.
3. Сделайте кнопку «Сбросить тему», удаляющую cookie.
