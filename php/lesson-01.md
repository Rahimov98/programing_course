# PHP · Урок 1. Введение, локальный сервер, Hello World

## Цели урока
- Понять, как PHP работает на сервере
- Установить локальный сервер
- Запустить первый PHP-файл

## Теория
PHP — серверный язык. Браузер запрашивает страницу, сервер выполняет PHP-код и отправляет клиенту готовый HTML. Пользователь не видит сам PHP-код. На PHP работают WordPress, Laravel и множество сайтов и API.

**Установка**
- Windows/macOS/Linux: [XAMPP](https://www.apachefriends.org/) (Apache + PHP + MySQL)
- Запустите **Apache** в панели XAMPP
- Файлы кладите в папку `htdocs` (например, `htdocs/hello/index.php`)
- Адрес в браузере: `http://localhost/hello/`

Быстрая альтернатива без Apache: `php -S localhost:8000` в папке проекта.

## Первая программа
```php
<?php
echo "Hello, World!";
```

Смешивание с HTML:
```php
<!DOCTYPE html>
<html lang="ru">
<head><meta charset="UTF-8"><title>PHP</title></head>
<body>
  <h1><?php echo "Привет из PHP!"; ?></h1>
  <p>Сегодня: <?php echo date("d.m.Y"); ?></p>
</body>
</html>
```

**Разбор**
- `<?php` — начало PHP-кода; в чистых PHP-файлах закрывающий `?>` не нужен
- `echo` — вывод текста
- Каждый оператор заканчивается `;`
- `date()` — встроенная функция даты
- Комментарии: `//`, `#`, `/* ... */`

## Типичные ошибки
- Открыли файл двойным кликом (`file://...`) — PHP не выполнится, нужен `http://localhost`
- Забыли `;` — «Parse error»
- Файл сохранён с расширением `.html` вместо `.php`

## Практика
1. Выведите свои имя и город с помощью двух `echo`.
2. Покажите текущее время: `date("H:i:s")`.
3. Сделайте страницу с заголовком, где имя выводится из PHP.

2. Почему PHP-файл нельзя просто открыть двойным кликом?
3. Что делает `echo`?
