# C++ · Урок 9. Строки (std::string)

## Цели урока
- Работать со строками через `std::string`

## Основы
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "Привет";
    string t = s + ", мир!";        // конкатенация
    cout << t << "\n";
    cout << t.length() << "\n";     // длина (в байтах!)
    cout << s[0];                   // доступ по индексу
}
```
Для кириллицы в UTF-8 каждый символ занимает 2 байта, поэтому `length()` и индексы считают байты, а не буквы. Для учебных задач используйте латиницу или специальные библиотеки для Unicode.

## Методы
```cpp
string s = "Hello, World";
s.size();               // 12
s.empty();              // false
s.substr(7, 5);         // "World"
s.find("World");        // 7 (или string::npos, если не найдено)
s.replace(0, 5, "Hi");  // "Hi, World"
s.append("!");          // добавить в конец
s.insert(2, "--");
s.erase(0, 2);
s.push_back('?');
s.pop_back();
s.front(); s.back();
s.clear();
```

## Сравнение
```cpp
string a = "abc", b = "abd";
if (a == b) { }
if (a < b) { }          // лексикографическое сравнение
```

## Преобразования
```cpp
int n = stoi("123");
double d = stod("3.14");
string str = to_string(42);
```
`stoi` бросает исключение при неверном формате.

## Перебор
```cpp
for (char c : s) cout << c << " ";
for (size_t i = 0; i < s.size(); i++) cout << s[i];
```

## Пример: подсчёт гласных
```cpp
int count = 0;
for (char c : s) {
    c = tolower(c);
    if (c=='a' || c=='e' || c=='i' || c=='o' || c=='u') count++;
}
```
Функции `<cctype>`: `isalpha`, `isdigit`, `isspace`, `toupper`, `tolower`.

## Типичные ошибки
- Сравнение с `string::npos` через `-1`
- Индекс за пределами строки в `s[i]` (безопасно: `s.at(i)` бросает исключение)
- Ожидание, что `length()` считает русские буквы
