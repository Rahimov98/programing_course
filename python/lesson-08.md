# Python · Урок 8. Списки и кортежи

## Цели урока
- Хранить наборы данных в списках
- Знать, чем кортеж отличается от списка

## Списки
```python
nums = [5, 2, 9, 1]
nums[0]              # 5
nums.append(7)       # добавить в конец
nums.insert(1, 100)  # вставить по индексу
nums.remove(9)       # удалить значение
last = nums.pop()    # удалить и вернуть последний
nums.sort()          # сортировка на месте
nums.reverse()
len(nums), sum(nums), min(nums), max(nums)
```

**Срезы и перебор**
```python
nums[1:3]
for n in nums:
    print(n)
for i, n in enumerate(nums):
    print(i, n)
```

**Списки списков**
```python
matrix = [[1, 2], [3, 4]]
print(matrix[1][0])   # 3
```

**Копирование**
```python
a = [1, 2, 3]
b = a          # та же ссылка!
c = a.copy()   # независимая копия
```

## Кортежи
Неизменяемые последовательности:
```python
point = (10, 20)
x, y = point        # распаковка
single = (5,)       # кортеж из одного элемента
```
Используйте кортежи для данных, которые не должны меняться (координаты, даты).

## Типичные ошибки
- `b = a` не копирует список
- `sort()` возвращает `None` — используйте `sorted(a)`, если нужна новая копия
- `remove` вызывает ошибку, если элемента нет

## Практика
1. Найдите второй по величине элемент списка.
2. Удалите из списка все дубликаты, сохранив порядок.
3. Транспонируйте матрицу 2×3.
