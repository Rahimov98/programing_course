# PHP · Урок 6. Функции

## Цели урока
- Объявлять и вызывать функции
- Передавать параметры (по значению и по ссылке)
- Возвращать значения и использовать значения по умолчанию

## Теория

**Объявление**
```php
function greet($name) {
    return "Привет, $name!";
}

echo greet("Алишер");  // Привет, Алишер!
```

**Параметры по умолчанию и типизация (PHP 7+)**
```php
function add(int $a, int $b = 0): int {
    return $a + $b;
}

echo add(5, 3);  // 8
echo add(5);     // 5
```

**Передача по ссылке**
```php
function double(&$n) {
    $n *= 2;
}

$x = 10;
double($x);
echo $x;  // 20
```

**Переменное число аргументов**
```php
function sum(...$numbers) {
    $total = 0;
    foreach ($numbers as $n) {
        $total += $n;
    }
    return $total;
}

echo sum(1, 2, 3, 4);  // 10
```

**Анонимные функции (замыкания)**
```php
$multiplier = 3;
$fn = function ($x) use ($multiplier) {
    return $x * $multiplier;
};
echo $fn(5);  // 15
```

**Стрелочные функции (PHP 7.4+)**
```php
$square = fn($x) => $x * $x;
echo $square(4);  // 16
```

## Типичные ошибки
- Вызов функции до её объявления (в PHP обычно работает, но лучше объявлять раньше)
- Забыли `return` — функция вернёт `null`
- Изменение параметра без `&` не влияет на исходную переменную

## Практика
1. Напишите функцию `isEven($n)`, возвращающую `true`/`false`.
2. Функция `maxOfThree($a, $b, $c)` — наибольшее из трёх.
3. Функция `greet($name = "Гость")` с значением по умолчанию.
