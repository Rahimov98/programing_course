# Веб · Урок 4. Списки и таблицы

## Цели урока
- Создавать маркированные, нумерованные и списки определений
- Строить таблицы
- Понимать, когда что использовать

## Теория

**Списки**
```html
<ul>  <!-- маркированный -->
  <li>Пункт один</li>
  <li>Пункт два</li>
</ul>

<ol>  <!-- нумерованный -->
  <li>Шаг 1</li>
  <li>Шаг 2</li>
</ol>

<dl>  <!-- определения -->
  <dt>HTML</dt>
  <dd>Язык разметки</dd>
  <dt>CSS</dt>
  <dd>Стили</dd>
</dl>
```

Вложенные списки:
```html
<ul>
  <li>Фрукты
    <ul>
      <li>Яблоко</li>
      <li>Банан</li>
    </ul>
  </li>
</ul>
```

**Таблицы**
```html
<table>
  <thead>
    <tr>
      <th>Имя</th>
      <th>Город</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Алишер</td>
      <td>Душанбе</td>
    </tr>
    <tr>
      <td>Мадина</td>
      <td>Худжанд</td>
    </tr>
  </tbody>
</table>
```

- `th` — заголовок ячейки
- `td` — обычная ячейка
- `thead` / `tbody` / `tfoot` — секции (для стилей и доступности)

**Объединение ячеек**
```html
<td colspan="2">На две колонки</td>
<td rowspan="2">На две строки</td>
```

## Типичные ошибки
- Список без `<li>`
- Таблица без `<tr>`
- Использование таблицы для вёрстки макета (устарело)

## Практика
1. Список ваших навыков (ul) и план на неделю (ol).
2. Таблица «расписание» или «контакты» с thead и tbody.
3. Вложенный список категорий.

## Проверь себя
1. Чем `<ul>` отличается от `<ol>`?
2. Зачем `thead` и `tbody`?
3. Когда использовать таблицу, а когда список?
