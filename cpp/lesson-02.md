# C++ · Урок 2. Переменные и типы данных

## Цели урока
- Объявлять переменные и константы
- Знать основные типы и их размеры

## Объявление
```cpp
#include <iostream>

int main() {
    int age = 21;
    double price = 19.99;
    char grade = 'A';
    bool isStudent = true;
    const double PI = 3.14159;

    std::cout << age << " " << price << " " << grade << " " << isStudent << "\n";
    return 0;
}
```
C++ — язык со **статической типизацией**: тип переменной задаётся при объявлении и не меняется.

## Основные типы
| Тип | Размер (обычно) | Что хранит |
|---|---|---|
| `bool` | 1 байт | `true` / `false` |
| `char` | 1 байт | символ или маленькое число |
| `short` | 2 байта | целое |
| `int` | 4 байта | целое (около ±2,1 млрд) |
| `long long` | 8 байт | большое целое |
| `float` | 4 байта | дробное (≈7 цифр) |
| `double` | 8 байт | дробное (≈15 цифр) |

Модификатор `unsigned` убирает отрицательные значения: `unsigned int`.

## sizeof и auto
```cpp
std::cout << sizeof(int) << "\n";    // размер типа в байтах
auto x = 3.5;                         // компилятор сам определит тип (double)
```

## Инициализация
```cpp
int a = 5;
int b(5);
int c{5};       // рекомендуется: запрещает потерю данных
int d;          // НЕ инициализирована — в ней мусор!
```

## Преобразование типов
```cpp
double x = 7 / 2;                       // 3 (целочисленное деление!)
double y = 7 / 2.0;                     // 3.5
int z = static_cast<int>(3.99);         // 3 (дробная часть отбрасывается)
```

## Переполнение
```cpp
int big = 2147483647;
big = big + 1;    // неопределённое поведение / отрицательное число
```

## Типичные ошибки
- Использование неинициализированной переменной
- Целочисленное деление вместо дробного
- Переполнение `int` при больших вычислениях — берите `long long`

## Практика
1. Выведите размеры всех основных типов.
2. Вычислите среднее двух целых чисел с дробной частью.
3. Объявите константу `const int DAYS = 7` и попробуйте её изменить — прочитайте ошибку.
