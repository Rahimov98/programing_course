# Python · Урок 19. Регулярные выражения

## Цели урока
- Искать и проверять текст по шаблонам
- Использовать модуль `re`

## Основные символы
| Шаблон | Значение |
|---|---|
| `.` | любой символ |
| `\d` / `\D` | цифра / не цифра |
| `\w` / `\W` | буква, цифра, `_` / остальное |
| `\s` | пробельный символ |
| `^` / `$` | начало / конец строки |
| `*`, `+`, `?` | 0+, 1+, 0 или 1 повторение |
| `{n}`, `{n,m}` | ровно n / от n до m |
| `[abc]`, `[a-z]` | набор символов |
| `( )` | группа |
| `\|` | «или» |

## Функции `re`
```python
import re

text = "Звоните: +992 900 12 34 56 или 900-00-11-22"

re.search(r"\d{3}", text)          # первое совпадение (объект или None)
re.findall(r"\d+", text)           # список всех совпадений
re.sub(r"\d", "#", text)           # замена
re.split(r"[,;]\s*", "a, b;c")     # разбиение
re.match(r"^\d+$", "12345")        # совпадение с начала строки
```
Шаблоны пишут как raw-строки `r"..."`.

## Группы
```python
m = re.search(r"(\w+)@(\w+\.\w+)", "mail: user@example.com")
if m:
    print(m.group(1), m.group(2))   # user example.com
```

## Пример: проверка email
```python
pattern = r"^[\w.+-]+@[\w-]+\.[\w.-]+$"
print(bool(re.match(pattern, "test@mail.ru")))
```

## Типичные ошибки
- Забыли `r` перед строкой — обратные слеши ломают шаблон
- Жадные квантификаторы `.*` захватывают лишнее — используйте `.*?`
- Регулярка для сложных задач (HTML, полная валидация email) не подходит
