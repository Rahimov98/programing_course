# Python · Урок 17. Генераторы и comprehensions

## Цели урока
- Писать компактные выражения для создания коллекций
- Понимать ленивые вычисления и `yield`

## List comprehension
```python
squares = [x ** 2 for x in range(1, 6)]           # [1, 4, 9, 16, 25]
evens = [x for x in range(10) if x % 2 == 0]
words = ["a", "bb", "ccc"]
lengths = [len(w) for w in words]
pairs = [(i, j) for i in range(2) for j in range(2)]
```

## Словарные и множественные
```python
sq = {x: x ** 2 for x in range(5)}       # {0: 0, 1: 1, 2: 4, ...}
unique = {c for c in "hello"}            # {'h', 'e', 'l', 'o'}
```

## Генераторные выражения
```python
total = sum(x ** 2 for x in range(1000000))   # без создания списка
```

## Генераторы с yield
```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for x in countdown(3):
    print(x)        # 3, 2, 1
```
Генератор выдаёт значения по одному и не хранит всё в памяти:
```python
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
```

## Когда что использовать
- Нужен список для повторного использования → list comprehension
- Данных много или они бесконечные → генератор
- Слишком сложное выражение → обычный цикл

## Типичные ошибки
- Генератор можно пройти только один раз
- Слишком длинные comprehension нечитаемы
- Забыли `[]` и получили генератор вместо списка

## Практика
1. Список кубов чисел от 1 до 10 нечётных.
2. Словарь «слово → его длина» для списка слов.
3. Генератор простых чисел, выдающий первые 10.
