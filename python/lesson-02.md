# Python · Урок 2. Переменные и типы данных

## Цели урока
- Создавать переменные и понимать динамическую типизацию
- Знать основные типы: `int`, `float`, `str`, `bool`
- Преобразовывать типы

## Теория
Переменная — имя, которое ссылается на значение. Тип определяется автоматически.

```python
age = 21            # int — целое
price = 19.99       # float — дробное
name = "Мадина"     # str — строка
is_student = True   # bool — True или False
nothing = None      # отсутствие значения

print(type(age))    # <class 'int'>
```

**Правила имён:** буквы, цифры, `_`; нельзя начинать с цифры; регистр важен (`age` ≠ `Age`). Принят стиль `snake_case`: `user_name`.

**Преобразование типов**
```python
x = int("15")       # 15
y = float("3.14")   # 3.14
s = str(100)        # "100"
b = bool(0)         # False (0, "", None, пустые коллекции — False)
```

**Множественное присваивание**
```python
a, b, c = 1, 2, 3
x = y = 0
a, b = b, a         # обмен значений
```

## Типичные ошибки
- `"5" + 5` → `TypeError`: нельзя сложить строку и число
- `int("abc")` → `ValueError`
- Имя `list` или `str` для переменной затирает встроенные функции
