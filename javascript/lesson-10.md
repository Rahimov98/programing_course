# JavaScript · Урок 10. Объекты

## Цели урока
- Создавать объекты, работать со свойствами и методами
- Копировать и перебирать объекты

## Создание
```js
const user = {
  name: "Алишер",
  age: 21,
  skills: ["JS", "SQL"],
  address: { city: "Душанбе" },
  greet() {
    return `Привет, я ${this.name}`;
  },
};

user.name;             // точечная запись
user["age"];           // скобочная (ключ может быть переменной)
user.email = "a@mail.ru";   // добавить
delete user.age;            // удалить
"name" in user;             // true
```

## Полезные методы
```js
Object.keys(user);       // массив ключей
Object.values(user);     // массив значений
Object.entries(user);    // массив пар [ключ, значение]
Object.assign({}, user); // поверхностная копия
```

## Копирование
```js
const copy = { ...user };            // поверхностная копия
const deep = structuredClone(user);  // глубокая копия
```
Вложенные объекты в поверхностной копии остаются общими.

## Короткая запись и вычисляемые ключи
```js
const name = "Мадина", age = 19;
const person = { name, age };            // { name: "Мадина", age: 19 }
const key = "city";
const o = { [key]: "Худжанд" };
```

## Необязательная цепочка
```js
user.address?.city;      // не упадёт, если address нет
user.phone?.number;      // undefined
```

## Типичные ошибки
- `const b = a` — не копия, а ссылка на тот же объект
- Сравнение `{} === {}` → `false`
- `this` теряется при передаче метода как обычной функции

## Практика
1. Создайте объект «книга» и функцию вывода её описания.
2. Массив объектов-студентов: найдите студента с максимальным баллом.
3. Подсчитайте количество свойств объекта.
