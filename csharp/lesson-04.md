# C# · Урок 4. Операторы

## Цели урока
- Использовать арифметические, логические операторы и операторы для `null`

## Арифметика
```csharp
int a = 17, b = 5;
Console.WriteLine(a + b);      // 22
Console.WriteLine(a - b);      // 12
Console.WriteLine(a * b);      // 85
Console.WriteLine(a / b);      // 3
Console.WriteLine(a % b);      // 2
Console.WriteLine(a / (double)b);   // 3.4
```

## Инкремент и составные
```csharp
int x = 5;
x++; ++x; x--; --x;
x += 3; x -= 1; x *= 2; x /= 4; x %= 3;
int y = x++;    // y — старое значение, потом x+1
int z = ++x;    // сначала x+1
```

## Сравнение и логика
```csharp
a == b; a != b; a > b; a >= b;
bool r = (a > 10) && (b < 10);    // И (ленивое)
bool o = (a > 10) || (b > 10);    // ИЛИ
bool n = !r;                      // НЕ
bool xor = a > 10 ^ b > 10;       // исключающее ИЛИ
```

## Тернарный оператор
```csharp
string status = age >= 18 ? "взрослый" : "ребёнок";
```

## Операторы для null
```csharp
string? name = null;
string display = name ?? "Гость";      // если null — «Гость»
name ??= "Аноним";                     // присвоить, если null
int? length = name?.Length;            // безопасный доступ
```

## Math
```csharp
Math.Sqrt(16);  Math.Pow(2, 10);  Math.Abs(-5);
Math.Round(2.567, 2);  Math.Floor(2.9);  Math.Ceiling(2.1);
Math.Max(3, 7);  Math.Min(3, 7);
new Random().Next(1, 101);        // случайное 1..100
```

## Битовые операции
`&`, `|`, `^`, `~`, `<<`, `>>`.

## Приоритет
Унарные → `* / %` → `+ -` → сравнения → `&&` → `||` → `??` → `?:` → присваивание. Сомневаетесь — ставьте скобки.

## Типичные ошибки
- Целочисленное деление вместо дробного
- `=` вместо `==`
- `Math.Round(2.5)` даёт `2` (банковское округление) — нужен `MidpointRounding.AwayFromZero`

## Практика
1. Разделите трёхзначное число на цифры.
2. Проверьте, что число чётное и положительное.
3. Вычислите площадь круга и длину окружности для введённого радиуса.

2. Что делает оператор `??`?
3. Что даёт `7 / 2` и `7 % 2`?
