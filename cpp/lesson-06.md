# C++ · Урок 6. Циклы: for, while, do-while

## Цели урока
- Повторять действия и управлять циклом

## for
```cpp
for (int i = 0; i < 5; i++) {
    std::cout << i << " ";       // 0 1 2 3 4
}
```
Три части: инициализация; условие; шаг.

## while
```cpp
int n = 5;
while (n > 0) {
    std::cout << n-- << " ";     // 5 4 3 2 1
}
```

## do-while
Тело выполняется минимум один раз:
```cpp
int x;
do {
    std::cout << "Введите число > 0: ";
    std::cin >> x;
} while (x <= 0);
```

## break и continue
```cpp
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;    // пропустить чётные
    if (i > 7) break;            // выйти из цикла
    std::cout << i << " ";       // 1 3 5 7
}
```

## Вложенные циклы
```cpp
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) std::cout << '*';
    std::cout << '\n';
}
```

## Range-based for (C++11)
```cpp
int arr[] = {10, 20, 30};
for (int v : arr) std::cout << v << " ";
```

## Примеры
```cpp
// сумма цифр числа
int n = 12345, sum = 0;
while (n > 0) { sum += n % 10; n /= 10; }

// НОД (алгоритм Евклида)
int a = 48, b = 18;
while (b != 0) { int t = a % b; a = b; b = t; }
```

## Типичные ошибки
- Бесконечный цикл (нет изменения переменной)
- `for (int i = 0; i <= n; i++)` — лишняя итерация при работе с массивами (выход за границы)
- Точка с запятой после `for (...);`
