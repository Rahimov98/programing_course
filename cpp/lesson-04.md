# C++ · Урок 4. Арифметические и логические операторы

## Цели урока
- Пользоваться операторами и знать их приоритет

## Арифметика
```cpp
int a = 17, b = 5;
a + b;    // 22
a - b;    // 12
a * b;    // 85
a / b;    // 3  (целочисленное деление)
a % b;    // 2  (остаток)
```
Для дробного результата хотя бы один операнд должен быть дробным: `a / 5.0`.

## Инкремент и составное присваивание
```cpp
int x = 5;
x++;  ++x;  x--;  --x;
x += 3;  x -= 1;  x *= 2;  x /= 4;  x %= 3;

int i = 5;
int p = i++;   // p = 5, i = 6 (постфикс: сначала значение, потом +1)
int q = ++i;   // i = 7, q = 7 (префикс: сначала +1)
```

## Сравнение
`==`, `!=`, `<`, `>`, `<=`, `>=` — результат `bool`.

## Логические
```cpp
bool a = true, b = false;
a && b;   // И — false
a || b;   // ИЛИ — true
!a;       // НЕ — false
```
Вычисление «ленивое»: в `a && b`, если `a == false`, `b` не проверяется.

## Побитовые операторы
```cpp
5 & 3;    // 1  (И)
5 | 3;    // 7  (ИЛИ)
5 ^ 3;    // 6  (исключающее ИЛИ)
~5;       // инверсия
1 << 3;   // 8  (сдвиг влево = умножение на 2^3)
16 >> 2;  // 4
```

## Тернарный оператор
```cpp
int m = (a > b) ? a : b;
```

## Приоритет
`!` → `* / %` → `+ -` → сравнения → `&&` → `||` → присваивание. Сомневаетесь — ставьте скобки.

## Типичные ошибки
- `=` вместо `==` в условии
- Деление на ноль (для целых — аварийное завершение)
- `if (a < b < c)` не проверяет диапазон — пишите `a < b && b < c`

## Практика
1. Разделите трёхзначное число на цифры (`%` и `/`).
2. Определите, чётное ли число, используя `%` и побитовое `&`.
3. Предскажите результат `int i = 2; int r = i++ + ++i;` и объясните, почему такие выражения писать нельзя.

2. Что вернёт `7 / 2` и `7 % 2`?
3. Что такое «ленивое» вычисление логических операторов?
