# Python · Урок 7. Строки

## Цели урока
- Работать с индексами и срезами
- Использовать методы строк

## Индексы и срезы
```python
s = "Python"
s[0]       # 'P'
s[-1]      # 'n'
s[1:4]     # 'yth'
s[:2]      # 'Py'
s[::-1]    # 'nohtyP' — разворот
len(s)     # 6
```
Строки **неизменяемы**: `s[0] = "J"` вызовет ошибку.

## Методы
```python
t = "  Привет, Мир!  "
t.strip()               # убрать пробелы по краям
t.lower(), t.upper()    # регистр
t.title()               # Каждое Слово С Заглавной
"a,b,c".split(",")      # ['a', 'b', 'c']
"-".join(["a", "b"])    # 'a-b'
"hello".replace("l", "L")
"hello".find("ll")      # 2 (или -1)
"hello".count("l")      # 2
"abc".startswith("a")   # True
"123".isdigit()         # True
```

## Конкатенация и повторение
```python
"ab" + "cd"    # 'abcd'
"-" * 20       # '--------------------'
```

## Пример: проверка палиндрома
```python
word = input("Слово: ").lower()
print("Палиндром" if word == word[::-1] else "Не палиндром")
```

## Типичные ошибки
- Пытаемся изменить символ строки по индексу
- Забываем, что методы возвращают **новую** строку: `s.upper()` не меняет `s`
- Выход за границы: `s[10]` → `IndexError` (срезы за границы безопасны)
