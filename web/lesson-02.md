# Веб · Урок 2. HTML: структура страницы

## Цели урока
- Понять структуру HTML-документа
- Использовать основные теги: html, head, body, title, meta
- Правильно вкладывать элементы

## Теория

**Минимальный документ**
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Заголовок вкладки</title>
</head>
<body>
  <!-- Содержимое страницы -->
</body>
</html>
```

**Разбор**
- `<!DOCTYPE html>` — режим стандартов HTML5
- `<html lang="ru">` — язык страницы (важен для скринридеров и SEO)
- `<head>` — метаданные (не видно на странице)
- `<body>` — видимое содержимое
- `<meta charset="UTF-8">` — кодировка (кириллица)
- `viewport` — корректное отображение на мобильных

**Вложенность и отступы**
```html
<body>
  <header>
    <h1>Сайт</h1>
  </header>
  <main>
    <p>Текст</p>
  </main>
</body>
```
Теги должны быть правильно закрыты и вложены. Нельзя: `<p><div></p></div>`.

**Комментарии**
```html
<!-- Это комментарий, браузер его не показывает -->
```

## Типичные ошибки
- Забыли закрыть тег
- `charset` не UTF-8 → кракозябры
- Контент вне `<body>`

## Практика
1. Создайте страницу с правильной структурой и заголовком «Моя визитка».
2. Добавьте meta viewport и charset.
3. В body напишите своё имя в `<h1>` и короткий текст в `<p>`.

## Проверь себя
1. Зачем нужен `<!DOCTYPE html>`?
2. Чем `<head>` отличается от `<body>`?
3. Почему важен `lang="ru"`?
