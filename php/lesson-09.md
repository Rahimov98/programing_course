# PHP · Урок 9. Формы: GET и POST

## Цели урока
- Создавать HTML-формы
- Получать данные через `$_GET` и `$_POST`
- Понимать разницу между методами

## Теория

**HTML-форма**
```html
<form action="process.php" method="post">
  <label>Имя: <input type="text" name="name"></label><br>
  <label>Возраст: <input type="number" name="age"></label><br>
  <button type="submit">Отправить</button>
</form>
```

**Обработка (process.php)**
```php
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = $_POST["name"] ?? "";
    $age  = $_POST["age"] ?? "";
    echo "Привет, $name! Тебе $age лет.";
}
```

**GET** — данные в URL (`?name=Алишер&age=21`):
```php
$name = $_GET["name"] ?? "Гость";
```

| | GET | POST |
|---|---|---|
| Данные | В URL | В теле запроса |
| Видимость | Видны в адресной строке | Не видны |
| Кеширование | Может кешироваться | Нет |
| Применение | Поиск, фильтры, ссылки | Пароли, большие данные, изменения |

**Суперглобальные массивы**
- `$_GET`, `$_POST`, `$_REQUEST` (оба + cookies)
- `$_SERVER` — информация о сервере и запросе
- `$_FILES` — загруженные файлы (урок 12)

## Типичные ошибки
- Забыли `name` у поля — данные не придут
- Обработка без проверки метода → данные при GET-запросе страницы
- Вывод сырых данных без экранирования (XSS — урок 21)

## Практика
1. Сделайте форму «Имя + email» методом POST и выведите данные.
2. Сделайте форму поиска методом GET и покажите результат.
3. Проверьте `$_SERVER["REQUEST_METHOD"]` и выведите сообщение, если форма ещё не отправлена.

## Проверь себя
1. Когда лучше использовать GET, а когда POST?
2. Что делает оператор `??`?
3. Где хранятся данные POST?
