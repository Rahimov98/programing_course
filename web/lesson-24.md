# Веб · Урок 24. Итоговый проект: сайт-портфолио

## Цель
Собрать одностраничный (или многостраничный) сайт-портфолио, применив HTML, CSS и немного JS. Опубликовать в интернете.

## Требования

**Структура**
- Шапка с именем и навигацией
- Блок «О себе»
- Блок «Навыки» (список или карточки)
- Блок «Проекты» (2–4 карточки с описанием и ссылкой)
- Блок «Контакты» (форма или ссылки)
- Подвал с годом и копирайтом

**Технологии**
- Семантический HTML5
- CSS: Flex и/или Grid, переменные, адаптив (mobile-first)
- Плавные transition на кнопках/карточках
- Небольшой JS: бургер-меню и/или переключатель темы
- Опубликован на GitHub Pages / Netlify / аналог

**Качество**
- Валидная структура, один h1
- Контрастный текст, видимый фокус
- Картинки с alt, при необходимости lazy
- title и meta description
- Работает на ширине 320px и 1200px+

## Рекомендуемая структура файлов
```
portfolio/
├── index.html
├── styles.css
├── script.js
├── images/
│   ├── avatar.jpg
│   └── project1.png
└── README.md
```

```css
:root {
  --color-bg: #0f172a;
  --color-text: #e2e8f0;
  --color-accent: #38bdf8;
  --max-width: 960px;
}

  max-width: var(--max-width);

  padding: 0 1rem;
}
```
