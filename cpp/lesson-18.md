# C++ · Урок 18. Наследование

## Цели урока
- Создавать иерархии классов
- Использовать `protected` и вызывать конструкторы базового класса

## Базовый и производный классы
```cpp
#include <iostream>
#include <string>

class Animal {
protected:                        // доступно в наследниках
    std::string name;
public:
    Animal(const std::string& n) : name(n) {}
    void eat() const { std::cout << name << " ест\n"; }
    void speak() const { std::cout << name << " издаёт звук\n"; }
};

class Dog : public Animal {
    std::string breed;
public:
    Dog(const std::string& n, const std::string& b)
        : Animal(n), breed(b) {}                    // вызов конструктора базового
    void speak() const { std::cout << name << " лает\n"; }    // скрытие метода
    void fetch() const { std::cout << name << " приносит палку\n"; }
};

int main() {
    Dog d("Рекс", "овчарка");
    d.eat();        // унаследован
    d.speak();      // переопределён в Dog
    d.fetch();
}
```

## Спецификаторы наследования
`class Dog : public Animal` — открытое наследование («Dog **является** Animal»). Используется в 99% случаев. `private` и `protected` наследование — для особых случаев.

## Порядок вызова
Создание: конструктор базового → конструктор производного.
Уничтожение: деструктор производного → деструктор базового.

## Вызов метода базового класса
```cpp
void speak() const {
    Animal::speak();
    std::cout << "И ещё лает\n";
}
```

## Множественное наследование
```cpp
class Duck : public Animal, public Flyer { };
```
Применяйте осторожно: возможна неоднозначность (проблема «ромба»).

## Композиция или наследование?
- «Является» (Dog is an Animal) → наследование
- «Имеет» (Car has an Engine) → композиция (поле-объект)

## Типичные ошибки
- Не вызвали нужный конструктор базового класса — ошибка, если у базового нет конструктора по умолчанию
- Поле `private` в базовом классе недоступно в производном (нужен `protected` или геттер)
- «Срезка» (slicing) при передаче объекта по значению как базового

## Практика
1. Иерархия `Shape` → `Rectangle`, `Circle`.
2. Классы `Employee` → `Manager`, `Developer` с расчётом зарплаты.
3. Постройте цепочку `A → B → C` и выведите порядок вызова конструкторов и деструкторов.
