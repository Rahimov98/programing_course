# C++ · Урок 8. Массивы

## Цели урока
- Хранить набор однотипных значений
- Работать с одномерными и двумерными массивами

## Объявление
```cpp
int nums[5] = {10, 20, 30, 40, 50};
int zeros[10] = {};              // все нули
int autoSize[] = {1, 2, 3};      // размер 3

std::cout << nums[0];            // индексы с 0
nums[2] = 99;
```
Размер массива в обычном массиве — константа, известная при компиляции.

## Перебор
```cpp
const int N = 5;
for (int i = 0; i < N; i++) std::cout << nums[i] << " ";
for (int v : nums) std::cout << v << " ";
```

## Размер массива
```cpp
int n = sizeof(nums) / sizeof(nums[0]);
```
Внутри функции этот приём не работает — массив «превращается» в указатель. Передавайте размер отдельно.

## Пример: максимум и сумма
```cpp
int mx = nums[0], sum = 0;
for (int i = 0; i < 5; i++) {
    if (nums[i] > mx) mx = nums[i];
    sum += nums[i];
}
std::cout << "Max = " << mx << ", среднее = " << sum / 5.0 << "\n";
```

## Передача в функцию
```cpp
void printArray(const int arr[], int size) {
    for (int i = 0; i < size; i++) std::cout << arr[i] << " ";
}
```
Массив передаётся по адресу, поэтому функция может его изменить.

## Двумерные массивы
```cpp
int m[2][3] = {{1, 2, 3}, {4, 5, 6}};
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) std::cout << m[i][j] << " ";
    std::cout << "\n";
}
```

## Сортировка пузырьком
```cpp
for (int i = 0; i < n - 1; i++)
    for (int j = 0; j < n - 1 - i; j++)
        if (arr[j] > arr[j + 1]) std::swap(arr[j], arr[j + 1]);
```

## Типичные ошибки
- Выход за границы (`arr[5]` для массива из 5) — неопределённое поведение, без предупреждения
- Использование неинициализированного массива
- Нельзя присвоить один массив другому: `a = b`

## Практика
1. Найдите второй по величине элемент.
2. Разверните массив на месте.
3. Найдите сумму элементов главной диагонали матрицы 3×3.

2. Что произойдёт при выходе за границы?
3. Как узнать размер массива?
