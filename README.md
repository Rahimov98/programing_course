# Курс программирования с нуля

Открытый курс для начинающих: **7 направлений × 24 урока = 168 уроков**.
Каждый урок содержит цели, теорию, примеры кода, практику и вопросы для самопроверки.

**Всего готово: 168 из 168. Курс завершён.**

## Как пользоваться
1. Выберите направление и откройте его папку.
2. Проходите уроки по порядку, выполняйте практику своими руками.
3. Для старта рекомендуем: **Python** или **JavaScript**; для работы с сайтами: **Веб → JavaScript → PHP → SQL**.
