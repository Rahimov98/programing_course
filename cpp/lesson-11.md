# C++ · Урок 11. Указатели

## Цели урока
- Понять адреса и указатели
- Безопасно разыменовывать и использовать арифметику указателей

## Адрес и указатель
Каждая переменная лежит в памяти по адресу. Указатель хранит этот адрес.
```cpp
int x = 10;
int* p = &x;         // p хранит адрес x

std::cout << p << "\n";     // адрес
std::cout << *p << "\n";    // 10 — разыменование
*p = 20;                    // теперь x == 20
```
- `&x` — взять адрес
- `*p` — значение по адресу

## nullptr
```cpp
int* q = nullptr;           // указатель «в никуда»
if (q != nullptr) { std::cout << *q; }
```
Разыменование `nullptr` приводит к аварийному завершению.

## Указатели и массивы
```cpp
int arr[3] = {10, 20, 30};
int* p = arr;               // имя массива — адрес первого элемента
std::cout << *p << " " << *(p + 1) << " " << p[2] << "\n";   // 10 20 30
p++;                        // сдвиг на один элемент (int)
```

## const и указатели
```cpp
const int* a;      // нельзя менять значение через a
int* const b = &x; // нельзя менять сам указатель
```

## Указатель на указатель
```cpp
int** pp = &p;
std::cout << **pp;
```

## Обмен значений через указатели
```cpp
void swapValues(int* a, int* b) {
    int t = *a;
    *a = *b;
    *b = t;
}
int x = 1, y = 2;
swapValues(&x, &y);
```

## Типичные ошибки
- Неинициализированный указатель (`int* p;` содержит мусор)
- Возврат адреса локальной переменной из функции
- Разыменование `nullptr`
- Путаница `*` при объявлении и при разыменовании

## Практика
1. Выведите элементы массива через арифметику указателей.
2. Напишите `swap` для двух `double` через указатели.
3. Найдите максимум в массиве, возвращая указатель на элемент.
