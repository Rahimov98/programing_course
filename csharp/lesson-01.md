# C# · Урок 1. Введение, .NET SDK, Hello World

## Цели урока
- Понять, что такое C# и платформа .NET
- Установить .NET SDK и создать консольный проект
- Запустить первую программу

## Теория
C# — современный язык от Microsoft. На нём пишут десктопные приложения, веб-сервисы (ASP.NET), игры (Unity) и мобильные приложения. Код компилируется в промежуточный язык и выполняется средой .NET.

**Установка**
- Скачайте [.NET SDK](https://dotnet.microsoft.com/download)
- Редактор: Visual Studio Community или VS Code с расширением «C# Dev Kit»
- Проверка: `dotnet --version`

## Создаём проект
```bash
dotnet new console -n HelloApp
cd HelloApp
dotnet run
```

## Первая программа
```csharp
Console.WriteLine("Привет, мир!");
```
Начиная с .NET 6 достаточно одной строки (top-level statements). Классическая форма выглядит так:

```csharp
using System;

namespace HelloApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Привет, мир!");
        }
    }
}
```

**Разбор**
- `using System;` — подключает пространство имён с классом `Console`
- `namespace` — группирует код проекта
- `class Program` — в C# весь код живёт внутри классов
- `Main` — точка входа
- `Console.WriteLine` — вывод строки с переводом строки

## Типичные ошибки
- Регистр важен: `console.writeline` не сработает
- Строки только в двойных кавычках `"..."`
- Забыли `;` в конце оператора

## Практика
1. Выведите имя, возраст и профессию тремя вызовами `WriteLine`.
2. Замените `WriteLine` на `Write` и посмотрите, чем отличается вывод.
3. Выведите ёлочку из символов `*` высотой 4 строки.

2. Зачем нужна точка входа `Main`?
3. Чем `Write` отличается от `WriteLine`?
