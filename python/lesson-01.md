# Python · Урок 1. Введение, установка, первая программа

## Цели урока
- Понять, где применяется Python
- Установить Python и редактор
- Запустить код в интерпретаторе и из файла

## Теория
Python — интерпретируемый язык с простым синтаксисом. Его используют в анализе данных, автоматизации, веб-разработке (Django, Flask), ИИ и для быстрых скриптов. Код читается почти как обычный английский.

**Установка**
- Скачайте Python с [python.org](https://www.python.org/downloads/) (на Windows поставьте галочку **Add Python to PATH**)
- Редактор: VS Code (расширение Python) или PyCharm Community
- Проверка: `python --version` (на Linux/macOS: `python3 --version`)

## Интерактивный режим
Введите `python` в терминале и попробуйте:
```python
>>> 2 + 3
5
>>> print("Привет!")
Привет!
```
Выход: `exit()`.

## Первая программа
Создайте файл `hello.py`:
```python
print("Hello, World!")
name = "Алишер"
print("Меня зовут", name)
```
Запуск:
```bash
python hello.py
```

**Разбор**
- `print()` — встроенная функция вывода
- Строки берутся в кавычки `"..."` или `'...'`
- `#` начинает комментарий
- Точка с запятой в конце строки не нужна
- Отступы — часть синтаксиса (подробнее в уроке об условиях)

## Типичные ошибки
- `Print("...")` — регистр важен
- Не закрыли кавычку или скобку
- Файл назван `random.py` или `python.py` — конфликт имён с модулями

## Практика
1. Выведите три строки о себе: имя, город, увлечение.
2. Вычислите в интерактивном режиме `15 * 12 + 7` и `2 ** 10`.
3. Добавьте в `hello.py` комментарий, объясняющий каждую строку.
