# PHP · Урок 2. Переменные и типы данных

## Цели урока
- Создавать переменные
- Знать основные типы: `int`, `float`, `string`, `bool`, `null`
- Преобразовывать типы

## Теория
Переменная начинается с `$`. Тип определяется автоматически.

```php
<?php
$age = 21;              // int
$price = 19.99;         // float
$name = "Мадина";       // string
$isStudent = true;      // bool
$nothing = null;        // null

echo gettype($age);     // integer
var_dump($name);        // string(6) "Мадина"
```

**Правила имён:** буквы, цифры, `_`; нельзя начинать с цифры; регистр важен (`$age` ≠ `$Age`). Принят стиль `camelCase` или `snake_case`.

**Преобразование типов**
```php
$x = (int)"15";         // 15
$y = (float)"3.14";     // 3.14
$s = (string)100;       // "100"
$b = (bool)0;           // false (0, "", null, [] — false)
```

Или функции: `intval()`, `floatval()`, `strval()`, `boolval()`.

**Константы**
```php
define("PI", 3.14159);
const SITE_NAME = "Мой сайт";   // с PHP 5.3+
echo PI;
```

## Типичные ошибки
- `$5name` — нельзя начинать с цифры
- `"5" + 5` работает (неявное приведение), но лучше явно
- Забыли `$` — «Undefined variable» или синтаксическая ошибка

## Практика
1. Создайте переменные с вашим именем, возрастом, ростом и признаком «студент».
2. Выведите тип каждой переменной через `gettype()` или `var_dump()`.
3. Преобразуйте строку `"42"` в число и сложите с 8.

## Проверь себя
1. Чем переменная отличается от константы?
2. Какие значения приводятся к `false`?
3. Что выведет `echo gettype(3 / 2);`?
