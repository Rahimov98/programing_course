# Веб · Урок 19. Bootstrap и Tailwind

## Цели урока
- Понять идею CSS-фреймворков
- Сделать макет на Bootstrap (обзорно)
- Познакомиться с утилитарным подходом Tailwind

## Теория

**Зачем фреймворки**
- Быстрый старт, готовая сетка и компоненты
- Единый вид кнопок, форм, модалок
- Минус: «все сайты похожи», лишний CSS, если не чистить

**Bootstrap (CDN)**
```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
```
```html
<div class="container">
  <div class="row">
    <div class="col-md-6">Левая колонка</div>
    <div class="col-md-6">Правая колонка</div>
  </div>
  <button class="btn btn-primary">Кнопка</button>
</div>
```

**Tailwind (идея)**
Утилитарные классы вместо своих CSS-правил:
```html
<button class="bg-blue-600 text-white px-4 py-2 rounded hover:bg-blue-700">
  Кнопка
</button>
```
Обычно подключается через сборщик (PostCSS), есть и Play CDN для экспериментов.

**Когда что**
| | Свой CSS | Bootstrap | Tailwind |
|---|---|---|---|
| Контроль | полный | средний | высокий |
| Скорость старта | ниже | высокая | высокая |
| Уникальный дизайн | легче | сложнее | легче |
| Размер | только нужное | может быть жирным | tree-shaking |

**Рекомендация для обучения**
Сначала освоить «голый» CSS (Flex, Grid, media). Фреймворки — ускорители, когда база есть.

## Типичные ошибки
- Тянуть весь Bootstrap ради одной кнопки
- Смешивать без системы свои стили и классы фреймворка
- Не читать документацию по сетке

## Практика
1. Подключите Bootstrap CDN и сделайте двухколоночный блок + кнопку.
2. (Опционально) Откройте Tailwind Play и соберите карточку утилитами.
3. Сравните: тот же блок на своём CSS.

## Проверь себя
1. В чём плюс и минус CSS-фреймворков?
2. Чем подход Tailwind отличается от Bootstrap?
3. Стоит ли начинать обучение с фреймворка?
