# C++ · Урок 1. Введение, компилятор, Hello World

## Цели урока
- Понять, что такое компилируемый язык и зачем нужен C++
- Установить компилятор и редактор
- Написать, скомпилировать и запустить первую программу

## Теория
C++ — компилируемый язык: исходный код (`.cpp`) превращается компилятором в исполняемый файл. Он быстрый и даёт контроль над памятью, поэтому на нём пишут игры, драйверы, браузеры и системы реального времени.

**Что нужно установить**
- Windows: [MSYS2/MinGW-w64](https://www.msys2.org/) или Visual Studio Community (рабочая нагрузка «Разработка на C++»)
- Linux: `sudo apt install g++`
- macOS: `xcode-select --install`
- Редактор: VS Code (расширение «C/C++») или CLion

Проверка установки: `g++ --version`

## Первая программа
```cpp
#include <iostream>   // подключаем библиотеку ввода-вывода

int main() {          // точка входа: с неё начинается программа
    std::cout << "Hello, World!" << std::endl;
    return 0;         // 0 означает «программа завершилась успешно»
}
```

**Разбор**
- `#include <iostream>` — подключает `cout` для вывода
- `int main()` — главная функция, она есть в каждой программе
- `std::cout << ...` — вывод в консоль; `std::` — пространство имён стандартной библиотеки
- `;` — обязательное окончание оператора
- `std::endl` — перевод строки

## Компиляция и запуск
```bash
g++ hello.cpp -o hello
./hello          # Windows: hello.exe
```

## Типичные ошибки
- Забыли `;` — ошибка компиляции на соседней строке
- Написали `cout` без `std::` — «cout was not declared»
- Файл сохранён как `hello.cpp.txt`
