# PHP · Урок 5. Циклы

## Цели урока
- Использовать `for`, `while`, `do-while`, `foreach`
- Управлять циклом через `break` и `continue`

## Теория

**for**
```php
for ($i = 1; $i <= 5; $i++) {
    echo $i . " ";
}
// 1 2 3 4 5
```

**while**
```php
$n = 1;
while ($n <= 5) {
    echo $n . " ";
    $n++;
}
```

**do-while** (тело выполнится хотя бы раз)
```php
$n = 1;
do {
    echo $n . " ";
    $n++;
} while ($n <= 5);
```

**foreach** (для массивов)
```php
$fruits = ["яблоко", "банан", "вишня"];
foreach ($fruits as $fruit) {
    echo $fruit . "\n";
}

foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit\n";
}
```

**break и continue**
```php
for ($i = 1; $i <= 10; $i++) {
    if ($i === 5) continue;  // пропустить 5
    if ($i === 8) break;     // выйти из цикла
    echo $i . " ";
}
// 1 2 3 4 6 7
```

## Типичные ошибки
- Бесконечный цикл (забыли увеличить счётчик)
- Изменение массива внутри `foreach` может дать неожиданный результат
- `for ($i = 0; $i < count($arr); $i++)` — лучше заранее сохранить `count`

## Практика
1. Выведите числа от 10 до 1.
2. Посчитайте сумму чисел от 1 до 100.
3. Выведите только чётные числа от 1 до 20.

## Проверь себя
1. Чем `while` отличается от `do-while`?
2. Когда удобнее `foreach`?
3. Что делает `continue`?
