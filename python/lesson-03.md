# Python · Урок 3. Ввод, вывод, f-строки

## Цели урока
- Получать данные от пользователя через `input()`
- Гибко выводить данные через `print()`
- Форматировать строки с помощью f-строк

## Теория
`input()` всегда возвращает **строку**, даже если введено число.

```python
name = input("Как вас зовут? ")
age = int(input("Сколько вам лет? "))
print("Привет,", name)
print(f"Через 5 лет вам будет {age + 5}")
```

**Параметры `print`**
```python
print("a", "b", "c", sep="-")     # a-b-c
print("Загрузка", end="...")      # без перевода строки
print()                           # пустая строка
```

**f-строки** — вставка выражений в `{}`:
```python
pi = 3.14159265
print(f"Число пи: {pi:.2f}")      # 3.14
print(f"{1000000:,}")             # 1,000,000
print(f"{'left':<10}|{'right':>10}|")
print(f"{7:03d}")                 # 007
```

**Экранирование:** `\n` — новая строка, `\t` — табуляция, `\"` — кавычка.

## Типичные ошибки
- Забыли `int()`: `input()` вернёт `"5"`, а не `5`
- Пользователь ввёл текст вместо числа → `ValueError` (обработаем в уроке об исключениях)
- Забыли букву `f` перед строкой — `{}` не подставятся
