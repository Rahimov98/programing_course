# Python · Урок 11. *args, **kwargs, lambda

## Цели урока
- Принимать произвольное число аргументов
- Использовать анонимные функции

## *args — позиционные аргументы
```python
def total(*args):
    return sum(args)

total(1, 2, 3, 4)   # 10
```
`args` внутри функции — кортеж.

## **kwargs — именованные аргументы
```python
def show(**kwargs):
    for k, v in kwargs.items():
        print(f"{k} = {v}")

show(name="Алишер", age=21)
```
`kwargs` — словарь.

## Распаковка при вызове
```python
nums = [1, 2, 3]
print(*nums)              # 1 2 3
data = {"name": "Мадина", "age": 19}
show(**data)
```

## Порядок параметров
`def f(a, b=1, *args, **kwargs)`

## lambda
```python
square = lambda x: x * x
add = lambda a, b: a + b
```
Чаще применяется как аргумент:
```python
people = [("Алишер", 21), ("Мадина", 19)]
people.sort(key=lambda p: p[1])

list(map(lambda x: x * 2, [1, 2, 3]))        # [2, 4, 6]
list(filter(lambda x: x % 2 == 0, range(10)))  # [0, 2, 4, 6, 8]
```

## Типичные ошибки
- Слишком сложные `lambda` — лучше обычная функция
- Неверный порядок параметров при объявлении
- Забыли `*`/`**` при распаковке
