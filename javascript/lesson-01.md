# JavaScript · Урок 1. Браузер, консоль, Hello World

## Цели урока
- Понять роль JavaScript в вебе
- Запустить код в консоли браузера и на HTML-странице
- Подключить внешний файл скрипта

## Теория
JavaScript — язык, который оживляет веб-страницы: реакция на клики, анимации, работа с сервером. Он выполняется прямо в браузере, а с помощью Node.js — и на сервере. Установка не требуется: достаточно браузера и редактора (VS Code).

## Консоль браузера
Откройте любую страницу, нажмите `F12` → вкладка **Console** и введите:
```js
console.log("Привет, мир!");
2 + 2
alert("Это окно из JavaScript");
```

## Скрипт на странице
Создайте `index.html`:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Мой первый JS</title>
</head>
<body>
  <h1>Привет!</h1>
  <script src="script.js"></script>
</body>
</html>
```
И рядом `script.js`:
```js
console.log("Скрипт подключён");
alert("Добро пожаловать!");
```
Откройте `index.html` в браузере и посмотрите консоль (`F12`).

**Разбор**
- `<script src="...">` подключает внешний файл; ставим перед `</body>`
- `console.log()` — вывод для разработчика
- `alert()` — окно с сообщением для пользователя
- `//` — однострочный комментарий, `/* ... */` — многострочный
- Точка с запятой в конце оператора рекомендуется

## Типичные ошибки
- Неверный путь в `src` — скрипт не загружается (смотрите вкладку Network/Console)
- Регистр: `Console.log` не работает
- Нет кодировки `UTF-8` — русский текст превращается в «кракозябры»

## Практика
1. Выведите в консоль своё имя и год рождения.
2. Покажите `alert` с приветствием.
3. Вычислите в консоли `365 * 24` — сколько часов в году.

## Проверь себя
1. Где выполняется JavaScript?
2. Чем `console.log` отличается от `alert`?
3. Почему скрипт подключают в конце `<body>`?
