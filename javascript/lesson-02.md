# JavaScript · Урок 2. Переменные (let, const) и типы данных

## Цели урока
- Объявлять переменные через `let` и `const`
- Знать примитивные типы и оператор `typeof`

## Объявление
```js
let age = 21;          // можно менять
const PI = 3.14159;    // менять нельзя
age = 22;
// PI = 3;             // TypeError
```
Используйте `const` по умолчанию, `let` — если значение будет меняться. `var` — устаревший способ, его лучше не применять.

**Имена:** буквы, цифры, `_`, `$`; не начинаются с цифры; принят `camelCase`: `userName`.

## Типы данных
```js
let n = 42;             // number (целые и дробные)
let s = "Привет";       // string
let ok = true;          // boolean
let empty = null;       // «пусто» (задано намеренно)
let notSet;             // undefined (значение не задано)
let big = 12345678901234567890n;  // bigint
let id = Symbol("id");  // symbol

console.log(typeof n);      // "number"
console.log(typeof s);      // "string"
console.log(typeof null);   // "object" — историческая ошибка языка
```
Объекты, массивы и функции — ссылочные типы (следующие уроки).

## Строки
```js
const name = "Алишер";
console.log(`Привет, ${name}! Через год тебе ${age + 1}`);  // шаблонная строка
console.log(name.length);
```

## Ввод от пользователя
```js
const answer = prompt("Ваше имя?");   // в браузере, всегда строка
```

## Типичные ошибки
- Повторное объявление `let x` в той же области видимости
- Обращение к `let`/`const` до объявления → `ReferenceError`
- `0.1 + 0.2 !== 0.3` — особенность чисел с плавающей точкой

## Практика
1. Объявите переменные с именем, возрастом и признаком «студент», выведите их типы.
2. Составьте приветствие через шаблонную строку.
3. Что выведет `typeof undefined`, `typeof NaN`? Проверьте в консоли.

1. Чем `let` отличается от `const`?
2. Чем `null` отличается от `undefined`?
3. Для чего нужны обратные кавычки?
