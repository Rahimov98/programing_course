# Python · Урок 10. Функции

## Цели урока
- Выносить повторяющийся код в функции
- Понимать параметры, возвращаемые значения и область видимости

## Определение
```python
def greet(name):
    """Приветствует пользователя."""
    print(f"Привет, {name}!")

greet("Мадина")
```

**Возврат значения**
```python
def square(x):
    return x * x

result = square(5)   # 25
```
Без `return` функция возвращает `None`. Можно вернуть несколько значений:
```python
def min_max(items):
    return min(items), max(items)

low, high = min_max([3, 1, 8])
```

**Параметры по умолчанию и именованные**
```python
def power(base, exp=2):
    return base ** exp

power(3)            # 9
power(2, 10)        # 1024
power(exp=3, base=2)
```

**Область видимости**
```python
x = 10              # глобальная
def f():
    x = 5           # локальная, не влияет на глобальную
    return x
```
Избегайте `global`; передавайте данные через параметры.

**Рекурсия**
```python
def factorial(n):
    return 1 if n <= 1 else n * factorial(n - 1)
```

## Типичные ошибки
- Вызвали `square` без скобок — получили объект функции
- Изменяемое значение по умолчанию: `def f(a=[])` — общий список на все вызовы
- Забыли `return`, получили `None`
